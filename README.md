# Probing E-service Mock

Mock service to simulate the status of e-services.

This repository contains both **REST** and **SOAP** endpoints for testing service status.

---

## REST Endpoints

- GET /rest/interop/probing/ok/status  
- GET /rest/interop/probing/error/status  
- GET /rest/interop/probing/random/status  

## SOAP Endpoints

- POST /soap/interop/probing/ok/status  
- POST /soap/interop/probing/error/status  
- POST /soap/interop/probing/random/status  

---

> See the OpenAPI spec (`probing.yaml`) for full details on responses, schemas, and examples.
